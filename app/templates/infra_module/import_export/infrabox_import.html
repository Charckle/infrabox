Import InfraBox data

Upload JSON or a full .ibxf backup. Import replaces all existing records for the affected object type(s). IDs and timestamps are preserved from the file.

Importing a single object type wipes every record of that type before loading the file. Server links (roles, products, programs, tags, location) only stay valid when IDs in the file match what servers reference — use a full backup restore or re-import servers after related types.
Full backup

Restores tags, server roles, products, programs, server locations, and servers in dependency order. If anything fails, all six types are rolled back to their pre-import state. Does not affect users.
