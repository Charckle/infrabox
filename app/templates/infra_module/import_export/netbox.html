Import from NetBox

Export objects from NetBox as CSV, then upload them here. Existing records with the same name are skipped.

{# ── Tags ── #}
Tags

NetBox export columns used: Name, Color, Description. Other columns (Items, Slug, ID, etc.) are ignored.

Example CSV format 
Name,Items,Slug,Color,Description,ID,Created,Last updated
Develop,58,develop,#4caf50,,6,2022-08-24 08:27,2022-08-24 11:37
Production,133,production,#2196f3,,4,2022-08-24 08:26,2022-08-24 11:38

{# ── Server Roles ── #}
Server Roles

Uses Name, Color, and Description. The Devices column is a count only — server links come from the server import (Roles column). Slug, ID, etc. are ignored.

Example CSV format 
Name,Devices,VMs,Color,VM Role,Description,ID,Slug,Tags,Created,Last updated
SQL Server,65,0,#795548,True,,2,sql-server,,2022-08-12 10:33,2022-08-12 10:33
ESB,23,0,#9e9e9e,True,Enterprise Service Bus,16,esb,,2023-10-13 14:02,2023-10-13 14:02
Misc,12,0,#9e9e9e,True,,15,misc,,2023-10-13 14:01,2023-10-13 14:02

{# ── Products ── #}
Products

Uses Name, Comments, and Devices. Messy whitespace in Devices is fine — each non-empty line is a server name to link. ID is ignored. Servers must already exist in InfraBox, or re-import after server import.

Example CSV format 
Name,Comments,Devices,ID
WebApp,,"web-app-01.example.com
web-app-02.example.com
web-backup-01.example.com",8
Billing,,"billing-app-01.example.com
billing-db-01.example.com",40
{{ products_form.csrf_token }} {{ render_field(products_form.import_file) }} {{ products_form.submit(class='btn btn-primary') }}
{# ── Programs ── #}
Programs

Uses Name, Comments, and Devices. Multiline or messy whitespace in Devices is fine — each line is a server name to link. ID is ignored. Servers must already exist in InfraBox (import servers first).

Example CSV format 
Name,Comments,Devices,ID
Reporting,,reporting-01.example.com,56
Web Server,,"web-proxy-01.example.com
web-proxy-02.example.com",47

{# ── Servers ── #}
Servers

Import last, after tags, roles, products, and programs. Resolves Roles, Products, Programs, and Tags by name. Status maps to InfraBox status (e.g. Active → active). Server Location is matched by name to an existing server location. ID and timestamps are ignored.

Example CSV format 
Name,Status,Roles,IP Address,URL,OS,Products,Programs,Comments,Tags,...,Server Location
git-01.example.com,Active,Misc,10.0.0.61,https://git.example/,Ubuntu 22.04,,Gitlab,gitlab,Production,...,DC1
db-01.example.com,Active,,10.0.0.71,,Ubuntu 18.04,,PostgreSQL,,Develop,...,DC1
